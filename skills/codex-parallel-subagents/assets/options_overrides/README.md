# Options Overrides Example

Run:

```bash
moon run .
```

Optional environment variables:

- `CODEX_PATH`: override the Codex CLI path.
- `CODEX_BASE_URL`: override the API base URL.
- `CODEX_API_KEY`: override the API key.
- `CODEX_WORKDIR`: set the per-thread working directory.
- `MODEL`: pick a model for the thread.
